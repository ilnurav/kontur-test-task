# Тестовое задание для XML/XSLT-разработчика (Контур)

## Структура репозитория

* **/javascript** — содержит файл `solutions.js` с решениями задач по JavaScript.
* **/xslt** — содержит 4 файла `*.xsl` с XSL-преобразованиями (версия 1.0) и папку с исходными XML-данными для тестирования.

## Запуск и проверка

### I. JavaScript
Все задачи по JavaScript объединены в один файл с настроенными `console.assert` для удобства тестирования.
Для запуска локально через Node.js:
```bash
node javascript/solutions.js
